## 💻 Sobre o projeto

Aplicação frontend construída para praticar Flexbox em profundidade, cumprindo requisitos específicos organizados em etapas progressivas — do layout básico de cabeçalho até desafios avançados de proporção e ordenação de elementos.

## 📚 Etapas do projeto

### 1️⃣ Flexbox e Cabeçalho — `feature/flexbox-cabecalho-1`
- Introdução
- Ajuste do cabeçalho
- Fluxo de logo e menu
- Posicionamento
- Propriedade `flex`
- Espaçamento com Flexbox
- Alinhamento vertical

### 2️⃣ Flexbox e Footer — `feature/flexbox-footer-2`
- Ajuste do footer
- Course map
- Espaçamento
- Verticalidade
- Próxima coluna

### 3️⃣ Flexbox e Grid Principal — `feature/flexbox-grid-3`
- Course grid
- Ajuste do course grid
- Grid
- Espaçamento do grid
- Espaçamento em detalhe

### 4️⃣ Flexbox e Mobile — `feature/flexbox-mobile-4`
- Responsivo
- Mobile
- `flex order`
- Vídeo
- Responsividade
- Fluxo desktop → mobile
- Flex container e flex items
- Ordenação do menu

### 5️⃣ Flexbox e Desafios — `feature/flexbox-challenge-5`
- Esclarecimento do projeto
- Propriedades flex
- Desafios
- Preenchimento de espaços vazios
- Cálculo no flex
- Manutenção de dimensões do vídeo
- Proporcionalidade dos elementos
- Largura dos elementos flex
- `flex-grow`, `flex-shrink`, `flex-basis`
- Inversão da ordem dos elementos
- Jogos e `align-self`
- Próximos passos
