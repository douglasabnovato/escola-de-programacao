1. O que é a Internet?

Muitos confundem Internet com Web. A Internet é a infraestrutura física (cabos submarinos, satélites, roteadores). A Web (WWW) é apenas um dos serviços que viajam nela, assim como o e-mail ou o WhatsApp.

2. Protocolo HTTP/S

É o "idioma" oficial da Web. Funciona em um ciclo de Request (Requisição) e Response (Resposta). O cadeado verde (HTTPS) indica que essa conversa está criptografada.

3. A Logística do Dado (TCP/IP)

Imagine que você quer enviar um caminhão de mercadorias da Volta Express. O dado é grande demais para uma viagem só, então o TCP/IP faz o seguinte:

  • Fatiamento Divide o arquivo em pequenos "pacotes".
  • Endereçamento Coloca o IP de destino em cada pacote.
  • Confirmação O servidor avisa se todos os pacotes chegaram. Se um sumir, ele pede o reenvio.

4. O Papel do DNS

Computadores falam por números (IPs: 192.168...). O DNS é o catálogo que traduz google.com para o IP correto, permitindo que humanos usem nomes fáceis.

5. Frontend vs Backend

O Frontend (o que fizemos até a aula 12) vive no Cliente. O Backend vive no Servidor, processando as regras de negócio e acessando o Banco de Dados.
