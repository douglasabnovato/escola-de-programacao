🚀 Simulador de Business Units

Calcule o valor do frete para Juiz de Fora.

🚨 BUG DETECTADO: O cálculo falhou ou gerou um valor inconsistente. Use o F12 > Sources para investigar as variáveis.

🔍 Task: Detetive de Código

  1. Abra o DevTools (F12) e localize a aba Sources.
  2. Encontre a função calcularSistema().
  3. Coloque um Breakpoint no retorno da função (Linha ~145).
  4. No painel Scope, verifique por que as variáveis de entrada aparecem como string.

Output de Sistema

> Sistema pronto para análise...

🎓 Solução Técnica: Tipagem Estrita

Independentemente da BU, o problema reside na coerção de tipos. O DOM sempre entrega valores como string.

Causa Raiz: "100" + 50 no JavaScript resulta em "10050".

A Correção (Clean Code):

const val1 = Number(document.getElementById('input-val-1').value);
const val2 = Number(document.getElementById('input-val-2').value);

💡 Dica do CTO: Em sistemas da MedTrem ou NCK Labs, um erro de centavos pode significar falhas em auditorias ou estouro de orçamento cloud.
