💡 Comandos da Aula:

  • git init: Cria o banco de dados do Git na pasta.
  • git status: Verifica em qual área os arquivos estão.
  • git add .: Move os arquivos para o palco (Staging).
  • git commit -m "mensagem": Tira a foto oficial do projeto.
