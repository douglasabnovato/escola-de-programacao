## 📝 Sobre a Escola de Programação

A **Escola de Programação** é o braço educacional do ecossistema **learnTECH**. Diferente de cursos tradicionais, nossa metodologia é baseada em **Projetos de Mundo Real (PBL)** e **Simulação de Business Units (BUs)**.

Preparamos o desenvolvedor para atuar desde a lógica fundamental até a arquitetura de sistemas complexos (Logística e E-commerce), utilizando padrões de mercado como **SOLID, Clean Code e UX Imersiva**. O **Nexus Hub** atua como o portal centralizador onde cada desafio é uma peça na construção de um perfil Sênior.

## 🚀 Galeria de Projetos (Nexus Inventory)

Abaixo, a listagem de todos os módulos e aplicações desenvolvidas e integradas ao motor NEXUS:

### 🛠️ Core & Fundamentos (Base Camp)

- **Uma Lâmpada:** Manipulação de eventos e troca dinâmica de assets (DOM).
- **Formulário de Login:** UX de autenticação e validação de dados client-side.
- **Curso em Vídeo:** Repositório de fundamentos e sintaxe JavaScript.

### 🎮 Game Engines (Logic & Physics)

- **Jogo da Cobra:** Algoritmo de crescimento de array e gestão de coordenadas.
- **Game Mario Bros:** Motor de colisões e animações baseadas em CSS Keyframes.
- **Jogo da Memória:** Gestão de estados (State Management) e comparação de objetos.
- **Jogo da Velha:** Lógica matricial para detecção de padrões de vitória.
- **Jogo Lost Decade:** Renderização de alta performance em HTML5 Canvas.
- **Pedra, Papel e Tesoura:** Implementação de lógica aleatória e fluxos condicionais.

### 🏢 Business Units & Bootcamps (Professional Track)

- **DIO + Estacionamento:** Sistema de gestão de pátio com logs temporais (BU Logística).
- **DIO + Contador:** Controle de estado em tempo real e limites lógicos.
- **DIO + ToDo List:** Aplicação CRUD com persistência de dados.
- **DIO + Operadores:** Engine de testes para lógica aritmética e binária.
- **DIO + Flex Box:** Laboratório de arquitetura de layouts responsivos.

### 🎨 UI/UX & Arquitetura (Frontend Mastery)

- **Home Instagram:** Engenharia de layouts complexos com Grid e Flexbox.
- **Sidebar Stack:** Template de navegação profissional com persistência de estado.
- **Receitas Deliciosas:** Componentização e estilização de cards estáticos.
- **Driven Aplicações:** Estruturação de Web Apps com foco em escalabilidade.
- **Rocketseat Explorer:** Projetos de semântica e acessibilidade HTML.

## 🏗️ Arquitetura do Projeto

O projeto utiliza a **NEXUS Engine v1.2**, que permite:

1.  **Persistência Híbrida:** O aluno nunca perde o progresso (LocalStorage + URL Hash).
2.  **Injeção Dinâmica:** Scripts são carregados sob demanda para otimizar a performance.
3.  **Bento Grid Design:** Interface inspirada nas tendências modernas de UX para Dashboards.
