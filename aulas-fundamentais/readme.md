## 🏗️ Estrutura Detalhada

### 🟢 Módulo 1: Fundamentos Web e Estrutura

- **Aula 01:** Introdução à Web – Protocolos HTTP/HTTPS, DNS e renderização.
- **Aula 02:** HTML5 Semântico – Estruturação, SEO e acessibilidade.
- **Aula 03:** CSS Box Model – Margins, Borders, Padding e Content.
- **Aula 04:** Posicionamento CSS – Display e Position (Relative, Absolute, Fixed).
- **Aula 05:** Flexbox I – Alinhamento de eixos.
- **Aula 06:** Flexbox II – Flex-grow, shrink e layouts flexíveis.
- **Aula 07:** CSS Grid Layout – Malhas complexas e áreas de template.
- **Aula 08:** Responsividade – Media Queries e Mobile First.
- **Aula 09:** Tipografia e Cores – Unidades (Rem, Em) e paletas.
- **Aula 10:** **Projeto Prático I** – Landing Page Institucional.

### 🟡 Módulo 2: Lógica de Programação e DOM

- **Aula 11:** Variáveis e Tipos de Dados – Let, Const, Strings, Numbers.
- **Aula 12:** Operadores Matemáticos e Lógicos.
- **Aula 13:** Estruturas Condicionais – If/Else e Ternário.
- **Aula 14:** Estruturas de Repetição – For, While e Do-While.
- **Aula 15:** Funções I – Declaração, Parâmetros e Escopo.
- **Aula 16:** Funções II – Arrow Functions e anônimas.
- **Aula 17:** Introdução ao DOM – Seletores e alteração de elementos.
- **Aula 18:** Manipulação de Eventos – Click, Submit, Input.
- **Aula 19:** **Projeto Prático II** – Hub de Exercícios Interativo.
- **Aula 20:** **Projeto Prático III** – Pokédex (Consumo de API externa).

### 🔴 Módulo 3: Persistência de Dados e CRUD

- **Aula 21:** Assincronismo – Promises e Async/Await.
- **Aula 22:** Sistema CRUD I – Estrutura JSON e Função Create.

- **Aula 24:** Sistema CRUD III – Função Delete e UX Feedback.
