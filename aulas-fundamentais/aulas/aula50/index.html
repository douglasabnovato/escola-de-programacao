Aula 50: SQL vs NoSQL

Escolhendo a Infraestrutura para as BUs

RELACIONAL (SQL)

Estrutura Rígida | Tabelas | ACID

SELECT v.placa, r.destino 
FROM veiculos v
JOIN rotas r ON v.id = r.veiculo_id
WHERE v.status = 'Ativo';
Ideal para: Volta Express (Financeiro, Notas Fiscais, Relações Complexas).
DOCUMENTO (NoSQL)

Estrutura Flexível | JSON-like | Escala

{
  "placa": "ABC-1234",
  "status": "Ativo",
  "historico_rotas": [
    {"destino": "Juiz de Fora"},
    {"destino": "São Paulo"}
  ]
}
Ideal para: MedTrem (Sensores de IoT, Logs de Auditoria, Chat em Tempo Real).

Dica ByteClass: "SQL é sobre relacionamentos previsíveis. NoSQL é sobre velocidade e volume de dados variados."
