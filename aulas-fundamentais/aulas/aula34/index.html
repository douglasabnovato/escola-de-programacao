Aplicando Clean Code no ecossistema learnTECH.

❌ Código "Sujo" (Legacy)

Variáveis genéricas, funções gigantes e repetição. 

function facalc() {
  var a = document.getElementById('v1').value;
  var b = document.getElementById('v2').value;
  var res = Number(a) + Number(b);
  document.getElementById('out').innerHTML = res;
  alert("Calculado");
}

function facalc2() {
  var a = document.getElementById('v3').value;
  var b = document.getElementById('v4').value;
  var res = Number(a) * 0.15;
  document.getElementById('out2').innerHTML = res;
}
🚩 Problemas: Nomes ruins (a, b, facalc), repetição de lógica de captura de DOM, falta de tratamento de erro.

✅ Clean Code (Padrão ByteClass)

Funções puras, nomes semânticos e modularidade. 

const getInputValue = (id) => Number(document.getElementById(id).value);

const calcularTaxaMedTrem = (valor) => valor * 0.15;

function processarOrcamento() {
    const totalVidas = getInputValue('input-vidas');
    const taxaFinal = calcularTaxaMedTrem(totalVidas);
    
    renderizarResultado(taxaFinal);
}
💎 Benefícios: Reutilização (DRY), fácil de testar, nomes que explicam a intenção do código.
