O que é o Git?

É o seu seguro de vida. Ele rastreia cada linha de código alterada. Se algo quebrar no learnTECH, você pode voltar para uma versão que funcionava em segundos.

GitHub vs Git

Git é a ferramenta instalada no seu PC. GitHub é a rede social/servidor onde guardamos os repositórios Git para que outros devs acessem.

Workflow de Ouro

Sempre faça o ciclo completo: Alterar -> add -> commit -> push. Nunca deixe seu código apenas na sua máquina!
