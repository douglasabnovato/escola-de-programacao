O que é uma API?

É um conjunto de regras que permite que sua aplicação peça dados ao servidor. Na Volta Express, o frontend pede a lista de caminhões e a API entrega no formato JSON.

O Papel do Garçom

O garçom (API) leva o seu pedido (Request) e traz o prato (Response). Se o prato não existe, ele traz um erro 404. Se a cozinha quebrou, ele traz um 500.

Verbos Principais

GET Ler dados.

POST Criar novo dado.

PUT Atualizar dado.

DELETE Deletar dado.
